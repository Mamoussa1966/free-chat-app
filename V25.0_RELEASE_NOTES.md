# V25.0 — CONVERSATION LEDGER + MESSAGE RUNTIME

Built directly on V24.0 / HOTFIX145 without deleting or replacing the prior Core.

## Scope
- Adds an authoritative V25 per-request and per-round ledger.
- Reconciles the real user Message ID with its Request ID and Round IDs.
- Stores one synthesis record per Message ID.
- Adds a two-message authoritative audit that reports NOT_PROVEN when Message #2 has not actually executed.
- Uses Application-Owned Runtime Records only; agent prose is never an identity/counter source.
- Existing provider, Free Cascade, Secrets, Transactional Bridge, HOTFIX131-144 and HOTFIX145 paths are preserved.

## No policy/configuration changes
- No Secrets changes.
- No Free Model list changes.
- No provider selection changes.
- No Paid fallback.
- No Local Engine.

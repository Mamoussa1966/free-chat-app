# HOTFIX141 — BRIDGE CONTROL + A/B/C LIFECYCLE HARNESS

Built directly from HOTFIX140.

## Scope
1. Bridge test control values for the HOTFIX141 A/B/C harness are generated by the application/runtime control plane and are never taken from the user prompt.
2. An explicit first-line `HOTFIX141_HARNESS=ABC` control activates a real sequential A/B/C lifecycle harness from one user submission. Each lifecycle receives a fresh runtime Request ID and an application-owned bridge value.

## Preserved contract
- No Secrets changes.
- No Models changes.
- No Free Cascade changes.
- No Local Engine.
- No Paid fallback.
- No Automatic Model Selection.
- Agent prose is never authoritative for Request ID, Bridge ID, status, model, attempt, classification, cascade action, or counters.
- Normal messages remain one Request lifecycle unless the explicit HOTFIX141 harness control is used.
- Existing files from HOTFIX140 are preserved; no files are deleted.

# HOTFIX164.30 — Deployed-Commit-Bound Live Closure

## Actual code changes

- The deployed read-only Bridge report now includes `deployment_attestation` generated by the running app, with a fresh UTC timestamp, the observed Git commit SHA when available, and SHA-256 hashes for the source bundle.
- The source fingerprint is built from the deployed application/runtime files, HOTFIX164.30 manifest, independent gate, and workflow. Missing files yield `NOT_PROVEN`.
- A new independent gate validates the prior canonical Request/Round and HTTP Bridge proof, then additionally requires a fresh runtime attestation (30-minute window), exact source-file hash-map equality, matching source-bundle SHA-256, and the selected deployed commit.
- A new GitHub Actions workflow saves the exported evidence before checking out the exact commit reported by the app, reruns the full regression suite, rebuilds a root-level package, checks the detached SHA-256, and only uploads the verified candidate after PASS.
- The frozen provider identity and `VERSION.txt` remain unchanged. No provider calls are performed by the attestation or independent gate.

## Required live procedure

1. Deploy this source to the intended Streamlit branch and wait for deployment to finish.
2. Open the app, run two new real Bridge tests, open **HOTFIX164.30 — Deployed Commit Closure Gate**, select both corresponding canonical Request IDs, run the read-only audit, and download `HOTFIX164.30_DEPLOYMENT_BRIDGE_EVIDENCE.json`.
3. Commit that JSON at `evidence/HOTFIX164.30_DEPLOYMENT_BRIDGE_EVIDENCE.json` on the repository branch. The source bundle excludes the evidence file itself, so this does not alter its code fingerprint.
4. Run **HOTFIX164.30 Deployed Commit-Bound Live Closure**. If the app host provides a Git SHA, the workflow checks out exactly that commit. Otherwise, enter the exact deployed commit SHA obtained from the Streamlit deployment details.

**Live final closure remains NOT_PROVEN until a fresh exported report passes this new independent gate.** Creating this source package or passing offline tests alone does not prove the deployed app is closed.

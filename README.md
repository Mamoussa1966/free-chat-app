AI Council V6
غرفة مجلس متعددة المزودين لـ Gemini وChatGPT وClaude وGrok وKimi.
التشغيل المحلي
pip install -r requirements.txt
streamlit run main.py
الأسرار
ضع مفاتيح المزودين في Streamlit Secrets أو متغيرات البيئة. لا توجد خانات مفاتيح في الواجهة.
ملاحظات هندسية
النظام لا يصنع وكلاء وهميين.
يكتشف نماذج المزود عند توفر واجهة listing، مع قائمة تفضيلية للنماذج الحالية.
يعزل المزود غير المتاح بدل استبداله بنموذج آخر من مزود مختلف.
التشغيل متوازٍ باستخدام ThreadPoolExecutor.
يوجد cache، وحماية من إعادة تشغيل السؤال بسبب rerun، وتصدير JSON/TXT.
الوضع العميق يستخدم جولة نقد متبادل، والمناظرة الكاملة تستخدم حَكَمًا من أحد الوكلاء الحقيقيين الناجحين، وليس نموذجًا سادسًا وهميًا.
النشر على Streamlit Cloud
ارفع main.py وrequirements.txt إلى المستودع، ثم أضف الأسرار من صفحة Secrets في إعدادات التطبيق.
